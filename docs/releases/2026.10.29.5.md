# Release 2026.10.29.5 — workflow designer visual refresh

Frontend presentation update. The workflow designer now has a clearer page header and empty state, version cards with status badges, a dedicated stage palette with icons, and a structured node inspector. Each of the nine stage types has its own icon and accent color; selected and running nodes have clear focus states. Connections use smooth paths with distinct approval/rejection colors.

The canvas, inputs and inspector support the existing light/dark themes. Workspace container queries move the version library above the editor when the application sidebar constrains available width. Mobile widths stack the inspector under the canvas. Keyboard focus and reduced-motion preferences are respected. Workflow styles were consolidated into a dedicated stylesheet shared by the designer and task detail viewer.

Validation: TypeScript/Vite production build; all seven existing frontend tests; visual browser review in light and dark themes and a 390px iframe viewport using the actual application. Temporary mobile preview files were removed before the final build. No production workflow definitions or tasks were changed during testing.

API remains 2026.10.29.3. This release has no database or workflow-engine changes and does not restart the API. Source changes are published to the frontend repository.

Rollback to frontend 2026.10.29.4:

`bash /opt/taskmanagment/releases/2026.10.29.5/rollback.sh --apply`

Run with `--check` to validate prerequisites without changing services. The previous image and Compose file are retained on the server.
